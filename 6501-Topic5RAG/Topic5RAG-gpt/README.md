## Brief findings
- Exercise 0: Built/loaded the ModelTService FAISS index (632 vectors). CongressionalRecord corpus was **missing** (`Corpora/CongressionalRecord/pdf_embedded`), so CR index build was skipped. Local LLM used: `Qwen/Qwen2.5-0.5B-Instruct` on CPU (to avoid MPS OOM/instability).
- Exercise 1: No-RAG answers often sounded plausible but were not grounded; RAG answers pulled manual-specific details (e.g., needle valve / dash adjustment) and included retrieval snippets + similarity scores.
- Exercise 2: Skipped (no `OPENAI_API_KEY`). File includes instructions.
- Exercise 3: Manual (web UI). File includes the query checklist + what to record.
- Exercise 4: Increasing top_k generally improved completeness up to a point; large k sometimes added noise/latency. Outputs include timing per k and retrieval excerpts.
- Exercise 5: Without strict prompting, off-topic questions could still get confidently answered; adding a strict grounding template improved refusal behavior (I cannot answer this from the available documents).
- Exercise 6: Query phrasing changes retrieval ranking and which chunks appear in top results; keyword-ish vs natural language phrasings can shift scores noticeably.
- Exercise 7: Overlap affects chunk count + retrieval continuity; moderate overlaps helped keep related sentences together, but high overlap increases redundancy.
- Exercise 8: Chunk size trades precision vs completeness; small chunks are more precise but can miss context, larger chunks bring more context but can dilute relevance.
- Exercise 9: Score distributions vary by query; some show clear winners while others cluster. Also tested a score threshold and observed that filtering can remove useful context if too strict.
- Exercise 10: Prompt template choice strongly affects groundedness and verbosity. Strict/citation templates reduce hallucination but can be less helpful if context is weak.
- Exercise 11: Failure-mode queries highlight typical RAG weaknesses (vagueness, multi-hop, negation). Results include retrieved context excerpts for analysis.
- Exercise 12: Cross-document synthesis is limited by retrieval: if key chunks arent retrieved, the model misses them. Increasing top_k can help but also increases irrelevant context.
